# 需求

## 核心需求

1. 领域优先的知识组织方式
2. 原始资料与结构化知识分离
3. 项目和知识分离
4. AI Agent 可维护
5. 来源可追溯
6. 支持多类型知识（技术、投资、视频、写作等）

## 功能需求

- 统一的 Frontmatter 规范
- 模板系统
- 状态流转（inbox → raw → seed → reviewed → evergreen → deprecated）
- 索引和知识地图
- 归档机制

## 非功能需求

- 不依赖特定插件（Dataview 可选）
- 支持 Obsidian 全平台
- Git 版本管理友好
- 易于人工维护
