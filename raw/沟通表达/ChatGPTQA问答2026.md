## 四阶段练习

### 第一阶段：一句话复述
目的是学会抓重点

### 第二阶段：三层复述
任何内容，都按三个层次说。


### 第三阶段：费曼训练
假装给三个对象讲。
对象不同。
说法也不同。

### 第四阶段：录音训练
这是提升最快的方法。
每天拿手机录音。

> Q1：为什么现在越来越多的程序员开始学习 AI，而不仅仅是学习编程？

MA：
```
因为现在AI非常发达,它不仅在编程方面有很大的提升,在其他方面也有挺大的提升,比如AI可以用来写代码,并且来做我们日常生活中的其他问题。比如,一,AI用来coding,二,AI可以用来处理日常中的文档。所以用Ai的人越来越多了
```

CA：
```
我认为主要有两个原因。

第一，AI 已经能够帮助程序员完成很多重复性的开发工作，比如写代码、排查 Bug、生成文档。

第二，现在很多企业都开始把 AI 能力作为开发人员的基本能力，所以程序员也需要主动学习 AI。
```

>Q2：如果领导问你："为什么我们要把 ERPNext 接入智能体，而不是让智能体单独回答问题？"

MA：
```
因为我们需要上端的ERP的数据源,如果只能智能体单独回答问题,可能会出现数据无所依据的问题,因此我们把ERPnextt接入智能体,提供了回答问题的数据来源。
```

```
我认为需要接入 ERPNext，因为智能体本身没有企业真实的数据来源。如果只依赖大模型回答，它更多是基于通用知识，回答可能与企业实际情况不一致。而接入 ERPNext 后，智能体可以基于订单、库存、采购等真实业务数据进行分析，因此回答会更准确，也更有依据。
```
