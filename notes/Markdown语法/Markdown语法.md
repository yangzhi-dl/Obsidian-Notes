## 1️⃣ 标题

```markdown
# H1（最大）
## H2
### H3
#### H4
##### H5
###### H6（最小）
```

**规则：**
- `#` 后**必须**有空格
- 一行只有一个标题
- H1 通常用作页面/文章标题，一页一个
- 闭合式写法（末尾加 `#`）可选，不强制

---

## 2️⃣ 段落与换行

```markdown
这是第一段。
同一行的连续文字。

这是第二段。（空一行分隔段落）

行尾加两个空格  
可以实现软换行（行间距较小）
```

**规则：**
- 段落之间用**空行**分隔
- 行尾两个空格 → 换行（`<br>`）
- 行尾反斜杠 `\` → 部分实现也支持换行

## 3️⃣ 文本格式

```markdown
**粗体** 或 __粗体__
*斜体* 或 _斜体_
***粗斜体*** 或 ___粗斜体___
~~删除线~~
`行内代码`
==高亮==（GFM 扩展，部分支持）
<u>下划线</u>（HTML 标签）
```

| 语法 | 结果 | 说明 |
|------|------|------|
| `**文本**` | **文本** | 最常用粗体 |
| `*文本*` | *文本* | 斜体 |
| `~~文本~~` | ~~文本~~ | 删除线 |
| `==文本==` | ==文本== | 高亮标记（需编辑器支持） |

**注意：** 符号前后不要有空格，否则可能被当作普通字符。

## 4️⃣ 列表

### 无序列表

```markdown
- 项目一
- 项目二
  - 子项目（缩进 2 或 4 空格）
  - 子项目
- 项目三

也可以用 * 或 + 代替 -：
* 项目
* 项目
```

### 有序列表

```markdown
1. 第一步
2. 第二步
   1. 子步骤（缩进 3 空格）
   2. 子步骤
3. 第三步
```

**技巧：** 有序列表所有项都用 `1.`，Markdown 会自动递增编号：

```markdown
1. 第一项
1. 第二项  
1. 第三项
```
→ 1. 第一项 2. 第二项 3. 第三项

### 混合列表

```markdown
1. 开启项目
   - 准备材料
   - 查阅文档
2. 执行
   - 编码
   - 测试
```

## 5️⃣ 代码

### 行内代码

```markdown
用 `console.log()` 打印日志。
```

### 代码块（围栏式）

```markdown
    ```python
    def hello():
        print("Hello, World!")
    ```
```

### 代码块（缩进式）

```markdown
    缩进 4 个空格或 1 个 Tab
    也是代码块（无语法高亮）
```

### 支持的语法高亮标识

```
bash, c, cpp, css, diff, go, html, java, javascript / js,
json, kotlin, markdown, php, python / py, ruby, rust,
scss, sql, swift, typescript / ts, xml, yaml, ...
```

### 行内代码中的转义

```markdown
`` `反引号自身` ``  → `反引号自身`
```

## 6️⃣ 链接

### 基本链接

```markdown
[显示文本](https://example.com)

[显示文本](https://example.com "鼠标悬停提示")
```

### 相对链接

```markdown
[关于我们](/about)
[图片](../assets/logo.png)
[同一仓库的文档](docs/guide.md)
```

### 引用式链接

```markdown
[显示文本][引用名]

[引用名]: https://example.com "可选标题"
```

### 隐式链接（引用名等于文本）

```markdown
[Google][]

[Google]: https://google.com
```

### 自动链接

```markdown
<https://example.com>
<user@example.com>
```

## 8️⃣ 表格

```markdown
| 左对齐 | 居中对齐 | 右对齐 |
|:-------|:--------:|-------:|
| 单元格 | 单元格   | 单元格 |
| 单元格 | 单元格   | 单元格 |
```

**规则：**
- 分隔线 `---` 至少 3 个 `-`
- 冒号 `:` 位置控制对齐方向
- 单元格内可以用 `|`、`**`、`链接`、`代码`、`换行`（`<br>`）
- 空单元格：`||`
- **表格前后要空行**，否则可能不渲染

### 缩短的写法（无对齐）

```markdown
| 标题 | 标题 |
| --- | --- |
| 内容 | 内容 |
```

## 🔟 水平线

```markdown
---

***

___
```

三种写法效果相同，都生成一条水平线。**前后需空行**（紧贴文字时可能被当作标题或粗体）。

## 1️⃣1️⃣ 转义字符

在 Markdown 特殊字符前加反斜杠 `\` 显示其字面含义：

```markdown
\* 这不是斜体 \*
\[这不是链接\]
\`代码反引号\`
```

**可转义的字符：**

```
\   `   *   _   {}   []   ()   #   +   -   .   !   |   ~
```

## 1️⃣3️⃣ 脚注

```markdown
这句话需要脚注说明[^1]。

另一处引用同一个脚注[^1]。

[^1]: 这里是脚注说明文字，可以
    多行（缩进 2 空格续写）。
```

**注意：** 脚注在各编辑器中支持程度不同。Obsidian 和 GitHub 都支持。

## 1️⃣8️⃣ 锚点（标题跳转）

Markdown 自动为每个标题生成锚点：

```markdown
[跳转到标题一](#1-标题)

[跳转到 code 部分](#5️⃣-代码)
```

**锚点规则：**
- 转为小写
- 空格变连字符 `-`
- 删除标点符号
- 中文标题按原样（部分解析器支持）

## 2️⃣1️⃣ 数学公式

### 行内公式

```markdown
$E = mc^2$

$\alpha + \beta = \gamma$
```

### 块级公式

```markdown
$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$

$$
f(x) = \int_{-\infty}^{\infty} \hat{f}(\xi) e^{2\pi i \xi x} d\xi
$$
```

**注意：** 需要编辑器/平台支持 LaTeX 数学（Obsidian 默认支持，GitHub 部分支持）。

## 2️⃣2️⃣ 图表（Mermaid）

    ```mermaid
    graph TD;
        A-->B;
        A-->C;
        B-->D;
        C-->D;
    ```

**支持的图类型：**

- `graph` / `flowchart` — 流程图
- `sequenceDiagram` — 时序图
- `classDiagram` — 类图
- `stateDiagram-v2` — 状态图
- `gantt` — 甘特图
- `pie` — 饼图
- `erDiagram` — ER 图
- `gitGraph` — Git 分支图
- `mindmap` — 思维导图

**注意：** Obsidian 原生支持 Mermaid，GitHub 也支持。

## 2️⃣3️⃣ HTML 内嵌

Markdown 中可以混写 HTML 标签：

```html
<div align="center">
  <h2>居中标题</h2>
  <p style="color: gray;">灰色文字</p>
</div>

<kbd>Ctrl</kbd> + <kbd>C</kbd>

<br/>     <!-- 换行 -->
&nbsp;    <!-- 空格 -->
&amp;     <!-- & 符号 -->
```

**常用 HTML 标签：**

| 标签 | 用途 |
|------|------|
| `<kbd>` | 键盘按键 |
| `<br>` | 换行 |
| `<hr>` | 水平线 |
| `<details><summary>` | 折叠块 |
| `<ins>` / `<u>` | 下划线 |
| `<sub>` / `<sup>` | 下标/上标 |
| `<span style="color:red">` | 彩色文字 |
| `<div align="center">` | 居中 |

## 2️⃣4️⃣ 注释

```markdown
<!-- 这是 HTML 注释，渲染后不可见 -->

[//]: # (这也是注释，部分平台支持)

[//]: <> (另一种注释写法)

<!-- 
多行
注释
-->
```

**注意：** Markdown 没有原生注释语法，以上两种是主流做法。

## 2️⃣5️⃣ YAML Frontmatter

```markdown
---
title: 文章标题
date: 2026-07-05
tags: [tag1, tag2, tag3]
author: 作者名
draft: false
---
```

**规则：**
- 文件最开头，三连 `---` 包裹
- 必须是有效的 YAML 格式
- Obsidian / Jekyll / Hugo / GitHub Pages 等都支持
- frontmatter 本身不会在渲染后显示
