# 按需阅读

> 687 个 Java 文件，你不需要看完——**只需要会的那部分。**

---

## 核心思想

不要试图全部学透再动手，而是：

```
遇到问题 → 定位相关代码 → 只读那部分 → 解决
               ↕
       需要更深 → 回溯扩散阅读范围
```

## 原则

- **先会用** — 看官方 Quick Start 就能上手
- **再理解原理** — 遇到 Bug 或性能问题时读源码
- **最后能改进** — 熟悉后贡献 PR

## 适用场景

| 场景 | 做法 |
|------|------|
| 接手老项目 | 不看全部代码，先改一个小 Bug 熟悉流程 |
| 学习新技术栈 | 不看全部文档，先跑通 Demo |
| 排查生产问题 | 只读异常堆栈涉及的那条路径 |
