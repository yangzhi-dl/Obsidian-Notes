# 提问的艺术

> 一个好问题，一半的答案已经有了。

---

## ❌ 错误的提问

> "这个项目怎么跑不起来？"

→ 太模糊，别人无法帮你。

## ✅ 正确的提问

> "我在启动项目时遇到了 `Connection refused: Milvus` 的错误，
> 我已经检查了 Milvus 的 Docker 容器状态是 running，端口 19530 也正常，
> 但应用还是连不上。我怀疑是配置中的 host 不对，你能帮我看一下吗？"

## 原则：四段式提问

| 要素 | 说明 |
|------|------|
| 你做了什么 | 启动步骤、配置情况 |
| 你期望什么 | 正常启动、返回正确结果 |
| 实际发生了什么 | 具体的错误信息 |
| 你已经排除了什么 | 检查了哪些可能性 |
