# 🌱 自生长知识库使用指南

> 一句话概括：**你投喂资料，AI 编译知识，知识库自己长大。**

---

## 🎯 核心工作流

```
收集 → 整理 → 查询 → 沉淀 → 维护
 ↓       ↓       ↓       ↓       ↓
你负责   AI负责   AI检索  你决定   AI检查
```

---

## 一、📥 收集：把资料丢进来

### 方式 A：用 Web Clipper（推荐）
1. 浏览器装 [Obsidian Web Clipper](https://obsidian.md/clipper)
2. 看到好文章 → 点图标 → 自动存到 `raw/文章/`
3. 剪藏后按 `Ctrl+Shift+D` 下载图片到本地

### 方式 B：随手记
在 Claudian 聊天面板说：

> **「记一下 我刚刚在想，双向链接其实是一种知识图谱的边」**

AI 会自动保存到 `raw/随记/`

### 方式 C：直接创建
在 Obsidian 里手动新建 `.md` 文件放到对应 `raw/` 目录。

---

## 二、🔧 整理：AI 帮你消化

当 `raw/` 里有新资料后，在 Claudian 聊天面板说：

> **「整理一下」**

AI 会自动：
1. 读取 `raw/` 中的新文件
2. 创建 `wiki/来源/` 摘要页
3. 提取核心概念 → `wiki/概念/`
4. 识别实体 → `wiki/实体/`
5. 所有页面加上 `[[双向链接]]`
6. 更新 `wiki/index.md` 索引
7. 记录到 `wiki/log.md`

---

## 三、🔍 查询：从知识库找答案

> **「查一下 什么是双向链接」**

AI 会：
1. 优先在 `wiki/` 中搜索已整理的知识
2. 综合多个相关页面回答
3. 在回答中引用来源

如果 wiki 里没有，AI 会回溯 `raw/` 原文给你。

---

## 四、📝 沉淀：把好内容固化

当你有高质量的问答或分析，说：

> **「把这段沉淀到 wiki」**

AI 会保存到 `wiki/综合/`，加入索引和双向链接，变成知识库的永久资产。

---

## 五、🏥 维护：定期体检

> **「检查健康度」**

AI 检查：
- ❓ 孤儿页面（没人链接的页面）
- 🔗 断链（`[[]]` 指向不存在的页面）
- ♻️ 概念重复
- 📋 index.md 是否覆盖所有页面

---

## 📂 完整目录说明

| 目录 | 谁维护 | 用途 |
|------|--------|------|
| `raw/文章/` | 你（Web Clipper） | 网页文章存档 |
| `raw/随记/` | 你（说"记一下"） | 碎片灵感 |
| `raw/论文/` | 你 | 论文/深度报告 |
| `raw/assets/` | Obsidian 自动 | 图片附件 |
| `wiki/来源/` | **AI** | 原始资料摘要 |
| `wiki/概念/` | **AI** | 核心知识概念 |
| `wiki/实体/` | **AI** | 人物/公司/工具 |
| `wiki/综合/` | **AI** | 分析/报告沉淀 |
| `wiki/index.md` | **AI** | 全局索引 |
| `wiki/log.md` | **AI** | 变更日志 |
| `wiki/hot.md` | **AI** | 会话热缓存 |

## ⚡ 快速上手（5 分钟）

```
第 1 步：找一篇好文章 → Web Clipper 存到 raw/文章/
第 2 步：在 Claudian 说「整理一下」→ AI 编译成 wiki 概念
第 3 步：在 Claudian 说「查一下 这篇文章讲了什么」
第 4 步：每天写日记 → diary/ 模板自动生成
第 5 步：周末说「检查健康度」→ 保持知识库整洁
```

## 💡 高阶技巧

### Dataview 动态表格
打开 `wiki/index.md`，下面的表格是自动生成的：

```dataview
TABLE tags, created FROM "wiki/概念" SORT created DESC
```

### 图谱视图
在 Obsidian 中打开 Graph View（左侧工具栏），直观看到知识之间的连接网络。

### Git 版本管理
```bash
cd 你的知识库目录
git status        # 查看改了什么
git diff          # 查看具体变更
git commit -am "更新了xxx"   # 手动提交
```

### 配合日记使用
每天写日记是投喂知识库最好的方式：
- 在日记中记录学到的内容
- 定期说 **「整理一下」** 把日记中的知识提炼到 wiki
