# 问题雷达

> 保持对问题的敏感度，**你的"踩坑经验"就是你的核心竞争力。**

---

## 是什么

一种主动积累问题经验的习惯系统：

```
读代码时 → 记录你觉得"奇怪"的地方
运行时   → 记录遇到的错误和解决方案
日常中   → 定期和 Leader 讨论你的发现
```

## 怎么做

### 1. 随手记
在代码中看到不合理的逻辑、看不懂的设计，随手记到日记或 `raw/随记/`：

> "这里为什么用 synchronized 而不是 ReentrantLock？查一下"

### 2. 错误日志
每次解决问题后，记录：

```markdown
- 问题：数据库连接失败
- 原因：Redis 没启动导致 SaToken 初始化报错
- 解决：先启动 Redis 再启动后端
```

这其实就是你日记里 **「遇到的坑」** 板块在做的事。

### 3. 定期回顾
- 每周回顾你记录的问题模式
- 哪些问题反复出现？能不能从根上解决？
- 哪些问题的解决方案可以自动化？

## 价值

- 新人问你"这个坑怎么解决"，你不用重新查
- 面试时"你遇到过最大的技术挑战是什么"——随手就有素材
- 长期积累会成为团队的"活文档"
