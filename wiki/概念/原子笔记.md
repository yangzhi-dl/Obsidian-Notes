# 原子笔记

> **原子笔记（Atomic Notes）** 是一种笔记方法论，主张每个笔记只包含一个概念、一个想法或一个事实，保持内容的最小化和聚焦。

## 概述

原子笔记原则源自 Zettelkasten（卡片盒笔记法）的现代实践：

- **单一主题** — 每个笔记只记录一个概念
- **自包含** — 每个笔记独立可理解，不依赖上下文
- **可链接** — 细粒度的笔记单元便于与其他笔记建立精确链接

## 为什么重要

1. **提高链接精度** — 粗粒度的笔记难以建立准确的连接
2. **促进知识重组** — 小单元更容易以新的方式组合
3. **降低认知负担** — 每个笔记聚焦一个想法，易于理解和维护
4. **增强复用性** — 原子化的知识单元可以在多个上下文中使用

## 实践建议

| 做法 | 说明 |
|------|------|
| **一个笔记 = 一个概念** | 不要让一个笔记涵盖多个主题 |
| **为笔记命名** | 标题应能准确反映核心内容 |
| **开始就链接** | 创建笔记时就思考它与其他笔记的关系 |
| **定期拆分** | 过大的笔记应及时拆分为多个原子笔记 |
