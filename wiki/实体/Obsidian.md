# Obsidian

> **Obsidian** 是一款强大的本地优先、基于 Markdown 的知识管理和笔记应用程序。它的核心理念是"连接你的思维"（Linking Your Thinking）。

## 概述

Obsidian 由 Shida Li 和 Erica Xu 开发，是一款跨平台笔记软件（支持 Windows、macOS、Linux、iOS 和 Android），以其**双向链接**和**本地优先**特性闻名。

## 核心特性

| 特性 | 说明 |
|------|------|
| **本地优先** | 笔记以纯 Markdown 文件存储在本地，完全归你所有 |
| **双向链接** | `[[ ]]` 创建链接，自动生成反向链接 |
| **图谱视图** | 可视化知识网络，发现隐藏关联 |
| **插件系统** | 丰富的核心 + 社区插件生态 |
| **Canvas** | 在白板画布上自由排列内容 |
| **命令面板** | `Ctrl/Cmd + P` 快速执行任意操作 |
