# 📄 代码阅读与学习方法论

> 来源：`raw/随记/2026-07-05-代码阅读与学习方法论.md`

## 概述
一篇关于如何高效阅读代码、正确提问、持续成长的实操经验总结。涵盖从阅读技巧到心态建设的完整方法论。

## 核心要点

1. **代码阅读技巧**：不要从头读，先看依赖和接口，再用 Git blame 追溯代码历史，画图辅助理解
2. **提问的艺术**：描述做了什么、期望什么、实际发生了什么、排除了什么
3. **费曼学习法**：能讲清楚才算真理解，主动做技术分享
4. **问题雷达**：持续记录"奇怪"的地方和踩坑经验
5. **心态建设**：687 个文件不需要全看完，按需阅读才是正道
